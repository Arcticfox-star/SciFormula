## 一、AGH 作用

| 项 | 内容 |
|---|---|
| AGH 承担的角色 | **智能体运行与执行底座**（规程 3.1 要求）。任务的规划、工具的调用、返回结果的判读与重试决策，全部发生在 AGH 一侧 |
| 接入方式 | 本项目实现一个零第三方依赖的 **MCP 服务器**（`mcp_server.py`），把 13 个工具经官方 MCP 通道注册进 AGH |
| 连续步骤 | 每次运行都是 6~7 步的连续闭环：列题目 → 载入数据 → 推断单位 → 构造候选库并量纲剪枝 → 稀疏回归 → 独立验证 |
| 人的介入 | **每一次工具调用都由人工批准**（AGH 的信任机制）；7 场会话共 68 次批准、其中 4 次被拒，拒绝记录同样保留在原件里 |

## 五、专业软件

**无。**

本机未安装也未使用 Octave / MATLAB / ngspice / Blender 等第三方专业软件，
因此本项目**不声称"连接专业软件"**。所有数值与符号计算由 numpy / sympy 完成，
是通用计算库而非专业软件。

（对照实验用到的 `gplearn` 是同类方法的**开源基线库**，仅用于横向对比，
不参与作品功能，详见 `docs/membership-statement.md`。）

## 六、仿真环境

**有：本项目自建的数值仿真实验台。**

| 项 | 内容 |
|---|---|
| 实现 | `simulator.py`（纯 numpy，无新依赖）|
| 方法 | **四阶龙格-库塔积分** ODE 产生轨迹，再由轨迹后处理得出仪器读数（过零检测、包络对数线性回归等）——**不是把闭式解直接代进去** |
| 场景 | 4 个：弹簧振子（周期）、阻尼振子（衰减常数）、RC 放电（时间常数）、开普勒轨道（比动能）|
| 精度自检 | 12 个参数点上测量值与闭式解的最大相对误差 **1.5e-12**（`python simulator.py --selftest`）|
| 经 AGH 驱动 | 3 个 MCP 工具：`list_simulations` / `run_simulation` / `run_sweep` |
| 会话证据 | `results/agh-session-sim.html`（会话 `6ea6a59e`，7 次调用、全部 completed、零失败）、`results/agh-trace-sim.md` |

它在闭环里的作用：模型选实验台 → 驱动 **60 次**数值积分 → 落盘成数据集 →
后续走"载入 → 推单位 → 剪枝 → 拟合" → **换一组参数当场重跑仿真**，
用真实读数当独立 oracle 做验证。

## 八、设备接口

**无。**

本项目未连接任何硬件设备或仪器接口。仿真实验台的"仪器读数"由数值积分轨迹后处理得出，
是对真实测量过程的**数值模拟**，不是真实设备采集——这一点如实说明，不做夸大。

（`data/observations/*.csv` 的格式即为"列名即变量名、最后一列即目标量"，
把同格式的**真实测量 CSV** 放进目录即可替换，算法一行不用改。
这是本项目为"将来接入真实数据"留的接口，但目前提交版本的实测数据均为合成数据。）
